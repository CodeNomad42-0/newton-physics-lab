# 牛顿三定律·交互式物理实验室

> **Newton's Playground** — 基于纯 HTML / CSS / 原生 JS 的 2D 物理教学网页，零框架、零构建，可直接静态托管。
> 对标《物理》必修1 §1.1.3、§1.2.1–§1.2.3 与必修2 §5.2，用「设参 + 运行」的演示方式把牛顿三大定律与平抛运动做成看得见的实验室。

---

## 功能特性

- **四关闯关式教学**
  - 关卡一 · 惯性迷局（牛一）：μ 可调的水平面，推一下看物体"保持原来运动状态"
  - 关卡二 · 加速度工坊（牛二）：F / m / v₀ 可调，V-t 图斜率 = 加速度（彩蛋：v₀ 为负时曲线穿过零点）
  - 关卡三 · 碰撞交锋（牛三）：两冰球完全弹性碰撞，A 球每次发射带随机 Y 轴偏转（必为非正碰），碰撞瞬间等大反向的力箭头沿连心线闪烁
  - 关卡四 · 平抛轨迹（抛体运动）：v₀ / h / g 自由设置，圆形抛体从台沿水平抛出，实时显示速度分解与预测轨迹、落点
- **看得见的物理**
  - 实时受力图（红 = 主动力/合力、蓝 = 摩擦力、黑虚线 = G/N）+ "受力透视"开关
  - V-t / X-t 心电图式滚动图表，半透明理论曲线叠加对比
  - 三段式动态公式看板：公式 → 代值 → 结果，随参数实时刷新
- **参数直接输入**：所有物理参数均用数字输入框（带 min/max/step 约束），无需拖动滑块
- **自研解析物理引擎**：60Hz 固定步长纯数学计算，不依赖任何物理引擎库，无浮点漂移
- **浅色实验室风 UI + CC0 音效**，中文字体（Noto Sans SC）内置

## 运行方式

### 本地预览
浏览器须经 HTTP(S) 访问（`file://` 直开无法加载字体/音效资源）。任选一种：

```bash
python3 -m http.server 8123
# 或
npx serve .
```

然后打开 `http://localhost:8123/index.html`。

### 静态托管
把仓库根目录的 `index.html`、`css/`、`js/`、`assets/` 一起上传到任意静态托管（GitHub Pages / Netlify / 对象存储等），通过网址直接访问即可。

## 操作说明

| 关卡 | 操作 |
| --- | --- |
| 牛一 | 在「摩擦系数 μ」输入框键入数值 → 点「推一下（v₀=5 m/s）」观察滑行与减速；「受力透视」切换 G/N 显隐 |
| 牛二 | 键入 F / m / v₀ / μ → 点「运行」按预设参数运动，「暂停 / 继续」切换，「重置」复位 |
| 牛三 | 键入两球质量与 A 球初速 → 点「发射 A 球（带随机 Y 偏转）」观察碰撞；纵向分量大小 0.25~1 m/s、方向随机，必为非正碰 |
| 抛体 | 键入初速度 v₀、抛出点高度 h、重力加速度 g → 绿色虚线实时预览预测轨迹与落点；点「抛出（水平初速）」后橙色实线为实际飞过的轨迹，抛体上显示 v_x（蓝）与 v_y（红）分解 |

## 标尺换算（物理 → 像素）

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `PX_PER_METER` | 60 | 1 米 = 60 px（所有关卡统一，网格 1 格 = 1 m） |
| `PX_PER_NEWTON` | 20 | 1 N = 20 px 箭头长度 |
| `PX_PER_SPEED` | 8 | 1 m/s = 8 px 箭头长度（仅关卡四速度分解） |

> 关卡四的高度参数上限为 4.5 m：地面线位于画布高度 72% 处（452 px 高画布即 325 px），1 m = 60 px 的方格比例下，4.5 m 台面即 270 px，抛出瞬间球体上边缘仍在 y ≈ 27 px，保证抛体完整可见且方格不变形。抛体圆心在台面上方一个半径处起抛、落到地面线上，圆心精确下落 h 米。
