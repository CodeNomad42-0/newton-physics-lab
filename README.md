# 交互式物理实验室 · 调节、观察、验证

> **Newton's Physics Lab** — 基于纯 HTML / CSS / 原生 JS 的 2D 物理教学网页，零框架、零构建，可直接静态托管。
> 对标《物理（必修1）》§1.1.3、§1.2.1–§1.2.3，用「设参 + 运行」的演示方式把牛顿三大定律、平抛运动与匀变速直线运动做成看得见的实验室。

---

## 功能特性

- **主菜单四关闯关式教学**
  - 关卡一 · 惯性迷局（牛一）：μ 可调的水平面，推一下看物体"保持原来运动状态"
  - 关卡二 · 加速度工坊（牛二）：F / m / v₀ / μ 可调，V-t 图斜率 = 加速度（彩蛋：v₀ 为负时曲线穿过零点）
  - 关卡三 · 碰撞交锋（牛三）：两冰球完全弹性碰撞，A 球每次发射带随机 Y 轴偏转（必为非正碰），碰撞瞬间等大反向的力箭头沿连心线闪烁
  - 关卡四 · 平抛轨迹（抛体运动）：v₀ / h / g 自由设置，圆形抛体从台沿水平抛出，实时显示速度分解与预测轨迹、落点
- **物理仿真弹窗（主菜单右上角「物理仿真」）**
  - 题型：匀变速直线运动（可用）；平抛运动（仅占位选项，暂未开放）
  - 「知三求二」自动匹配公式：在 v₀ / v / a / t / x 中任填 3 个已知量，留空 2 个由系统判断用哪条公式求解，10 种组合全部覆盖，无解或数据矛盾时给出中文提示
  - 四类基本公式：`v = v₀ + a·t`、`x = v₀·t + ½·a·t²`、`v² = v₀² + 2a·x`、`x = (v₀ + v)/2 · t`
  - 逐步推导 + 求解结果回填（自动算出的输入框标橙色）
  - 运动动画：物块上标合外力 F，速度 v 与加速度 a 矢量浮于物块上方；下方带时间刻度的位移标尺
  - 画布下半部分内置进度条，支持拖动 / 播放暂停 / ←→ 逐帧步进（1/60 s）/ 空格切换，用于逐帧回放检验
  - V-t 图 / X-t 图收在底部折叠坞中，点击展开；拖动进度条时曲线按当前时刻同步重建
- **看得见的物理**
  - 实时受力图（红 = 主动力/合力、蓝 = 摩擦力、黑虚线 = G/N）+ "受力透视"开关
  - V-t / X-t 心电图式滚动图表，半透明理论曲线叠加对比
  - 三段式动态公式看板：公式 → 代值 → 结果，随参数实时刷新
- **参数直接输入**：所有物理参数均用数字输入框（带 min/max/step 约束），无需拖动滑块
- **自研解析物理引擎**：60Hz 固定步长纯数学计算，不依赖任何物理引擎库，无浮点漂移
- **浅色实验室风 UI + CC0 音效**，中文走系统字体（苹方 / 微软雅黑 / Noto Sans CJK），不加载网络字体
- **移动端适配**：手机竖屏访问时整页自动横转 90°（沿用云·原神网页版的强制横屏做法），把手机横过来即为 16:9 全屏画面；横屏状态不再旋转，画布内的拖拽坐标已做逆旋转换算，两种姿态下都能准确操作

## 运行方式

### 本地预览
浏览器须经 HTTP(S) 访问（`file://` 直开无法加载字体/音效资源）。任选一种：

```bash
python3 -m http.server 8123
# 或
npx serve .
```

然后打开 `http://localhost:8123/index.html`。

### 静态托管
把仓库根目录的 `index.html`、`css/`、`js/`、`assets/` 一起上传到任意静态托管（GitHub Pages / Netlify / 对象存储等），通过网址直接访问即可。

## 操作说明

| 关卡 | 操作 |
| --- | --- |
| 牛一 | 在「摩擦系数 μ」输入框键入数值 → 点「推一下（v₀=5 m/s）」观察滑行与减速；「受力透视」切换 G/N 显隐 |
| 牛二 | 键入 F / m / v₀ / μ → 点「运行」按预设参数运动，「暂停 / 继续」切换，「重置」复位 |
| 牛三 | 键入 A / B 球质量、A 球初速与阻力系数 k → 点「发射 A 球（带随机 Y 偏转）」观察碰撞；纵向分量大小 0.25~1 m/s、方向随机，必为非正碰 |
| 抛体 | 键入初速度 v₀、抛出点高度 h、重力加速度 g → 绿色虚线实时预览预测轨迹与落点；点「抛出（水平初速）」后橙色实线为实际飞过的轨迹，抛体上显示 v_x（蓝）与 v_y（红）分解 |
| 物理仿真 | 主菜单点「物理仿真」→ 选题目类型（匀变速直线运动）→ 在 v₀ / v / a / t / x 中任填 3 个、留空 2 个由系统自动匹配公式 → 点「求解并仿真」看推导、结果与运动动画 → 拖动进度条或按 ← / → 逐帧检验，点底部折叠坞展开 V-t / X-t 图 |

## 标尺换算（物理 → 像素）

| 比例 | 值 | 含义 |
| --- | --- | --- |
| `PX_PER_METER` | 60 | 1 米 = 60 px（所有关卡统一，网格 1 格 = 1 m） |
| `PX_PER_NEWTON` | 20 | 1 N = 20 px 箭头长度 |
| 关卡四速度分解 | 8 | 1 m/s = 8 px 箭头长度（关卡四内部比例） |
| 仿真弹窗矢量 | 8 | v / a / F 均按 1 单位 = 8 px 绘制，并设像素上限防止出屏 |

> 关卡四的高度参数上限为 4.5 m：地面线位于画布高度 72% 处（452 px 高画布即 325 px），1 m = 60 px 的方格比例下，4.5 m 台面即 270 px，抛出瞬间球体上边缘仍在 y ≈ 27 px，保证抛体完整可见且方格不变形。抛体圆心在台面上方一个半径处起抛、落到地面线上，圆心精确下落 h 米。

> 仿真弹窗画布的地面线改为距底部 96 px，下半部分固定留给时间刻度与逐帧进度条。
